Project Statement

Project Title

Song Recommendation System

Problem Statement

When a user has many songs to choose from, finding songs similar to a particular song can take time. This project solves that problem by comparing musical features and recommending songs that are similar to the song selected by the user.

Scope

The project focuses on content-based song recommendation using a self-contained dataset. It uses numerical song features and two machine learning based approaches: Cosine Similarity and K-Nearest Neighbors.

Target Users

This project is suitable for students, learners, and users who want a simple example of how AI/ML techniques can be used to build a recommendation system.

Objectives

1. Recommend songs similar to a selected song.
2. Prepare and standardize numerical song features.
3. Use Cosine Similarity and KNN for recommendations.
4. Evaluate recommendation quality using Precision@K.
5. Keep the project modular and easy to test.

High-Level Features

1. Song listing.
2. Cosine Similarity recommendation.
3. KNN recommendation.
4. Recommendation evaluation.
5. Command-line interface.
6. Automated testing.

Inputs

The user provides a song name. The user can also choose the number of recommendations and the recommendation method.

Outputs

The system displays a ranked list of recommended songs with the artist, genre, and similarity score.
